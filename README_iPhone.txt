MURILLO URGENCIAS — VERSIÓN iPHONE/PWA

Archivos:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-180.png
- icon-192.png
- icon-512.png

Para instalar en iPhone:
1. Publica esta carpeta en un sitio HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Abre la URL con Safari en el iPhone.
3. Pulsa Compartir > Añadir a pantalla de inicio.

Después de la primera carga, la app queda disponible offline mediante el service worker.
El progreso se guarda en localStorage del iPhone. Usa Exportar JSON para copias de seguridad.
